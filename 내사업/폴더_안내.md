# 내사업 폴더 구조

```
내사업/                        ← ChatGPT 워크 앱 프로젝트에 연결하는 폴더
├── 내사업_세컨드브레인.md      ← 원본. 항상 최상단, 파일명 고정
├── 01_랜딩/                   1주차 · index.html
├── 02_콘텐츠/                 2주차 · 블로그 / 쓰레드 / 카드뉴스
├── 03_자동발행/               3주차 · 앱이 읽고 쓰는 곳 (글감 / 발행완료)
├── 04_퍼널/                   3~4주차 · 폼 응답 · 리드
├── _자료/                     사진·후기·기존 링크
└── _설정/.env                 토큰·키 (깃허브·채팅 절대 금지)
```

원칙: 숫자 = 주차 · 세컨드 브레인만 최상단 · `_` 접두어는 도구용
앱에 시킬 때: "01_랜딩 폴더에 저장해 줘", "02_콘텐츠/블로그 폴더에 저장해 줘"
