# 공식 출처와 유지관리

자료 확인일: 2026-09-05. 배포본: 1.0.0.

이 스킬은 OpenAI 공식 문서를 바탕으로 작성한 교육용 응용 가이드이며 OpenAI 공식 배포 스킬이 아니다. 원문을 복제하지 않고 작업에 필요한 원칙과 수강생용 예제를 정리했다.

## 근거와 적용

| 공식 문서의 요지 | 이 스킬에서의 적용 |
|---|---|
| Astra는 결과에 영향을 주는 정보가 부족하면 질문하는 경향이 있다. | 핵심 불확실성만 질문하고 사소한 사항은 판단해 진행한다. |
| 스킬·파일의 상충하거나 모호한 지침에 민감할 수 있다. | 업무용 스킬과 작업 가이드의 역할을 나누고 사용자 조건을 우선한다. |
| 상세하고 형식화된 답변을 만드는 경향이 있다. | 필요한 분량·말투·형식을 작업별로 맞춘다. |
| 작은 코딩 작업에도 검증이 과도해질 수 있다. | 구체적인 위험과 완료 기준에 맞게 검증한다. |

출처: [Using GPT-6 Astra](https://developers.openai.com/api/docs/guides/latest-model).

위 원칙은 활용 방법이며 결과 품질 향상의 정량적 보증이 아니다. 핵심 규칙에 특정 벤치마크 점수, 요금제, 가격을 고정하지 않는다.

## 유지관리 방법

사용자가 업데이트를 요청하거나 최신 기능의 확인이 필요할 때만 다음을 수행한다.

1. 공식 가이드에서 제목이 'Using GPT-6 Astra'인 부분을 확인한다. latest-model 페이지가 새 모델 중심으로 바뀌어도 Astra 지침을 다른 모델의 설명으로 바꾸지 않는다.
2. 모델 고유 사양은 [GPT-6 Astra 모델 페이지](https://developers.openai.com/api/docs/models/gpt-6-astra), 변경일은 [API 변경 기록](https://developers.openai.com/api/docs/changelog)과 대조한다.
3. 사용 환경과 호출 방법은 [모델 안내](https://learn.chatgpt.com/docs/models), [스킬 제작 안내](https://learn.chatgpt.com/docs/build-skills), [Skills & Plugins](https://learn.chatgpt.com/docs/skills-and-plugins)에서 확인한다.
4. 접근할 수 없으면 마지막 확인일과 미확인 항목을 표시한다. 검색 결과 일부만으로 새로운 기능이나 제공 대상을 확정하지 않는다.
5. 실제로 확인한 내용만 수정하고 확인 날짜와 배포본 버전을 갱신한다. 업데이트 결과를 저장했다고 말하기 전에 저장 상태를 확인한다.

정기 조회나 수강생에게 수정본을 자동 발송하는 기능은 포함하지 않는다.
