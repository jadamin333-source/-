# 수강생 사용 안내와 실습 예제

## 무엇을 받는가

astra-work-guide는 Astra에 일을 맡길 때 질문 기준, 작업 진행, 문체, 결과 검토를 조정하는 교육용 스킬이다. OpenAI의 공식 배포물이 아니며, 별도 프로그램이나 API 키 없이 지침을 적용하는 형태다. 모델·도구 이용에는 본인 계정의 이용 조건이 적용된다.

이 스킬에는 네이버 블로그 전용 작성 스킬이나 자동 발행 도구가 포함되어 있지 않다. 함께 제공받은 업무용 스킬이 있으면 조합해서 사용할 수 있다.

## 강사의 배포 방법

1. 본인 스킬 목록에서 **Astra 작업 가이드**를 연다.
2. 해당 화면에서 제공되는 공유 기능으로 수강생이 접근할 수 있는 범위와 공유 링크를 확인한다.
3. 그 공유 링크와 아래 안내문을 수강생에게 전달한다. 강사 본인의 스킬 상세주소를 복사한 것만으로 다른 계정의 접근이 허용됐다고 판단하지 않는다.
4. 공유 화면에 외부 수강생을 위한 옵션이 없으면 조직·요금제의 공유 범위를 확인한다. 이 스킬만으로 공유 제한을 변경할 수 없다.

계정과 화면에 따라 메뉴 이름과 제공 여부가 다를 수 있다. 링크를 보냈다는 사실과 수강생이 설치에 성공했다는 사실을 구분한다.

## 수강생의 시작 순서

1. 강사가 제공한 공유 링크를 본인 계정으로 연다. 설치·추가 기능이 제공되면 안내에 따라 추가한다.
2. 새 대화에서 스킬 목록에 **Astra 작업 가이드**가 보이는지 확인한다.
3. 계정에 Astra가 제공되면 모델 선택 메뉴에서 고른다. 이 스킬이 모델을 대신 선택하지 않는다.
4. ChatGPT에서는 @로 해당 스킬을 선택하고 요청을 입력한다. Codex CLI·IDE에서는 $astra-work-guide로 호출한다. 화면에서 스킬이 선택됐는지 확인한다.
5. 설치 직후 보이지 않으면 스킬 페이지를 새로고침하거나 다시 열고 새 대화에서 확인한다.

공식 호출 방식: [스킬 제작 안내](https://learn.chatgpt.com/docs/build-skills). 모델 제공 여부: [모델 안내](https://learn.chatgpt.com/docs/models).

모델을 Astra로 변경한 것만으로 스킬이 호출되는 것은 아니다. 관련 요청에서 자동 선택될 수 있지만, 실습에서는 직접 선택하는 방식이 명확하다.

## 실습 1 — 블로그 원고 만들기

아래 예제의 대괄호를 본인 정보로 채운다. 사례를 제공하지 못하면 해당 항목은 비워두고 실제 사례를 지어내지 않도록 한다.

> Astra 작업 가이드를 적용해 네이버 블로그 원고를 완성해줘.
> 내 상품·서비스: [설명]
> 대상 독자: [누구인지]
> 독자의 질문: [질문 하나]
> 확인된 실제 사례: [제공 가능한 사실만]
> 제목 후보 5개, 결론을 먼저 제시하는 첫 문단, 소제목 3개, Q&A 3개를 포함해줘.
> 본문은 공백 포함 약 1,800자, 말투는 쉽고 친근하게 해줘.
> 수치와 후기는 만들지 말고, 확인되지 않은 내용은 제외해줘.
> 원고를 검토하고 수정한 뒤 보여줘. 이번 요청은 원고 작성까지야.

블로그 전용 스킬을 별도로 설치했다면 그것도 함께 선택한다. 스킬이 없어도 위 조건으로 원고를 요청할 수 있다. 홈판 노출이나 AI 추천 여부는 이 실습의 완료 기준에 포함하지 않는다.

## 실습 2 — 자료를 강의안으로 바꾸기

> Astra 작업 가이드를 적용해 첨부 자료로 30분 실습 강의안을 만들어줘.
> 대상은 AI를 처음 배우는 소상공인이야.
> 설명 10분, 따라 하기 15분, 결과 확인 5분으로 구성해줘.
> 수강생이 입력할 예제와 실습 성공 여부를 확인할 기준을 포함해줘.
> 자료에 없는 제품 기능이나 성과는 만들지 마.

## 실습 3 — 작업 중 방향 조정

작업 중 추가 입력을 지원하는 화면에서는 진행 중 다음을 입력한다. 지원하지 않으면 첫 답변 뒤에 후속 요청으로 입력한다.

> 대상 독자를 50대 자영업자로 바꾸고 어려운 용어를 줄여줘. 기존 주제와 전체 분량 조건은 유지해줘.

확인할 점: 바뀐 독자가 반영됐는지, 원래 주제와 분량 조건을 유지했는지, 제공하지 않은 사례를 만들지 않았는지 살펴본다.

## 수강생에게 보낼 안내문

> 오늘 특강 실습용 **Astra 작업 가이드**를 공유합니다.
> [강사가 확인한 공유 링크]
> 링크에서 스킬을 추가한 뒤, 새 대화에서 @로 **Astra 작업 가이드**를 선택하세요.
> 사용 가능한 경우 모델은 Astra로 선택하고, 본인의 상품 설명이나 강의 자료와 함께 요청하면 됩니다.
> “Astra 작업 가이드를 적용해 이 자료로 블로그 원고를 완성해줘.”
> 이 자료는 공식 문서를 바탕으로 만든 교육용 응용 가이드입니다. 네이버 자동 발행 도구는 별도로 필요합니다.
